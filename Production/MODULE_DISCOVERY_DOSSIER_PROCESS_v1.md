# Module Discovery Dossier Process
## For Modules 13+ (New Module Design)

### Purpose

Before designing any new module, systematically survey our 26
clinical sources to identify therapeutic techniques, guided
practices, and skill-building approaches that:

1. Haven't been covered by Modules 1-12
2. Are clinically validated for children ages 7-10
3. Could teach a distinct skill (not a context-variation of
   an existing one)
4. Translate naturally to the Everdale framework (creature +
   metaphor + Phase A demo + Phase B practice)

This dossier generates IDEAS. It feeds into Step 0 of the Module
Authoring Guide's design process (§0.1: Therapeutic Mechanism
Validation Gate) — not into script writing.

The key difference from the Phase B Research Dossier: that document
asks "how do we guide a technique we've already chosen?" This
document asks "what techniques should we consider choosing?"

---

### Phase 1 — Landscape Survey

#### 1a. Map What's Already Covered

Before searching for new techniques, document what Modules 1-12
already teach. This prevents proposing skills that duplicate
existing modules.

| Domain | Modules | Skills Covered | Therapeutic Territory |
|--------|---------|---------------|----------------------|
| Calm | 1, 2 | Diaphragmatic breathing, extended exhale | Parasympathetic activation via breath |
| Focus | 3, 4 | Cognitive defusion (observer stance), sustained attention on fading stimulus | Relationship to thoughts, attention regulation |
| Kindness | 5, 6 | Loving-kindness/self-compassion, apology/repair | Warmth toward self and others, relational repair |
| Courage | 7, 8 | Anxiety approach/exposure, worry containment (name-it-to-tame-it) | Approaching fear, managing worry |
| Grounding | 9, 10 | Sensory grounding (5 senses), progressive muscle relaxation | Body-anchored present-moment awareness |
| Rest | 11, 12 | Body scan/permission to release, acceptance/stop-fighting | Physical release, mental release for sleep |

#### 1b. Identify Gaps

For each domain, ask:
- What aspects of this therapeutic territory are NOT covered?
- What would a child therapist say is missing from this toolkit?
- Are there common childhood challenges that none of the 12
  modules address?

Common therapeutic gaps to check:
- Gratitude / savoring (beyond Win step)
- Anger regulation (distinct from anxiety/worry)
- Grief / loss processing
- Transitions / change management
- Social anxiety (distinct from general anxiety)
- Impulse control / pause-before-acting
- Emotional identification / literacy
- Mindful movement (walking, stretching — beyond PMR)
- Visualization / safe place imagery
- Journaling / reflective expression

### Phase 2 — Source-by-Source Discovery

For each of the 26 clinical sources, search for techniques and
practices that:

1. Fall within an identified gap from Phase 1
2. Are validated for children or easily adaptable to 7-10
3. Have enough structure to become a guided practice (not just
   a concept)

#### Research Questions Per Source

**For each source, investigate:**

1. **Unexplored techniques:** What practices from this source
   have we NOT used in Modules 1-12? List each one.

2. **Child applications:** Has this source (or practitioners
   who cite them) published child-specific guided practices
   we could learn from? What formats do they use?

3. **Distinct skills:** For each technique found, apply the
   Distinctiveness Test (Authoring Guide §0.1a): "Would a
   7-year-old who completed all 12 existing modules experience
   this as a genuinely NEW skill?"

4. **Metaphor potential:** Could this technique be represented
   visually? What would the Phase A demo look like? What creature
   scenario would make it concrete? (Rough ideas only — not
   full design.)

5. **Practice feasibility:** Could a 7-year-old practice this
   with eyes closed in 45-90 seconds? Does it require physical
   props, a partner, extended time, or other conditions we
   can't provide in-app?

#### Per-Source Output Template

```
### [Source Name]

**Already used in Modules:** [list]
**Unused techniques:**
1. [Technique name] — [brief description]
   - Clinical basis: [what it does / why it works]
   - Child-appropriate? [yes/no/with adaptation]
   - Distinct from existing modules? [yes/no — why]
   - Metaphor potential: [rough visual idea]
   - Practice feasibility: [can a child do this in 45-90s?]

2. [Next technique] ...

**Cross-references:** [Other sources that validate or expand
on these techniques]
```

### Phase 3 — Candidate Evaluation

#### 3a. Compile Candidate List

From all 26 source surveys, compile a master list of candidate
techniques. Each candidate includes:

- Technique name and brief description
- Primary source + supporting sources
- Which gap it fills (from Phase 1b)
- Which domain it belongs to (existing or new?)
- Distinctiveness score (high/medium/low)
- Feasibility score (high/medium/low)
- Metaphor readiness (can we visualize this? rough idea?)

#### 3b. Apply the Validation Gate

For each candidate, run the Therapeutic Mechanism Validation Gate
(Authoring Guide §0.1a):

1. **Clinically supported?** At least 1 primary source cited.
2. **Age-appropriate for 7-10?** Not a scaled-down adult technique.
3. **Distinct from existing modules?** Passes distinctiveness test.
4. **Efforting or releasing?** Effort type matches therapeutic goal.

Candidates that fail any gate are set aside (not discarded —
they may be viable with redesign).

#### 3c. Prioritize

Rank surviving candidates by:

1. **Therapeutic value:** How much would this skill help the
   target population? (Child therapist perspective)
2. **Gap coverage:** Does it fill the most significant missing
   area?
3. **Source density:** How many of our 26 sources support this
   technique? (More sources = more confidence)
4. **Design feasibility:** How naturally does this map to the
   Everdale framework?
5. **Domain balance:** Does adding this module create imbalance
   across domains?

### Phase 4 — Discovery Dossier Output

For each top-priority candidate, produce a Discovery Dossier:

```
# Module Discovery Dossier: [Proposed Module Name]

## Proposed Technique
[Name and description]

## Clinical Foundation
- Primary: [source, key concepts]
- Supporting: [2-4 sources with specific contributions]

## Gap Analysis
- What existing modules DON'T cover that this would: ...
- Why this is a distinct skill, not a variation: ...

## What the Child Learns
- Core insight (one sentence): ...
- What their body/mind does during practice: ...
- When they'd use this in real life: ...

## Rough Metaphor Ideas
- Possible creature scenario: ...
- Possible Phase A visual metaphor: ...
- Possible interaction shape: ...

## Phase B Practice Sketch
- What the guided practice would involve: ...
- Physical cues: ...
- Duration estimate: ...

## Source Research Summary
[Key findings from each relevant source — sequences,
language, metaphors, cautions]

## Validation Gate Results
1. Clinically supported: [yes — cite]
2. Age-appropriate: [yes/needs adaptation — explain]
3. Distinct: [yes — explain how]
4. Effort type matches goal: [efforting/releasing — explain]

## Open Questions
[What needs to be resolved before design begins?]
```

This dossier feeds directly into Step 0 of the Module Authoring
Guide. The module designer starts with research, not intuition.

---

### Key Differences from Phase B Research Dossier (Modules 1-12)

| | Phase B Research (1-12) | Module Discovery (13+) |
|---|---|---|
| **Phase A exists?** | Yes, locked | No |
| **Technique chosen?** | Yes | No — choosing is the goal |
| **Research question** | "How do we guide THIS technique?" | "WHAT technique should we teach?" |
| **Constrained by** | Phase A metaphor and vocabulary | Only by therapeutic gaps and validation gates |
| **Output feeds** | Phase B script writing (production process) | Module design process (Authoring Guide §0) |
| **Metaphor search** | Checking compatibility with existing metaphor | Generating possible metaphors |
| **When used** | After Phase A is locked, before script | Before any module design begins |
