# Phase B Meditation Script Production Process

## Purpose

This document defines the step-by-step process for writing Phase B
meditation scripts for all 12 MindfulNest modules. Phase B is where
the actual therapeutic experience happens. Phase A is the tutorial;
Phase B is the practice. Every word matters.

The scripts are written BEFORE engine work begins. They serve as the
validation layer for Phase A's design: if a script reveals that
Phase A's metaphor doesn't transfer to eyes-closed guidance, the
Phase A demo is corrected while demos are still editable.

## Constraints

- Duration: 60-120 seconds of guided practice (timed by reading aloud
  at warm, slow narrator pace — approximately 2 words per second).
  Introductory modules (first in a domain) target ~90s; later modules
  may use the full range as the child develops practice capacity.
- Audience: Ages 7-10, many experiencing guided practice for the first
  time
- Delivery: Pre-recorded audio with warm, grandparent-like narrator
  voice (ElevenLabs)
- Screen: Gentle visual guide for children who peek (breathing circle,
  body outline, ambient glow — NOT a visual the child needs to watch)
- Entry: Child has just watched Phase A demo, heard the bridge cue
  ("Close your eyes. Listen to the voice on the wind."), and has
  eyes closed
- Exit: Script ends, Guide Bird speaks Rescue sustain ("That's
  great... stay right there...")

---

## Step 0 — Research Dossier (PREREQUISITE)

Before beginning Step 1, a Phase B Research Dossier must exist for
this module. See PHASE_B_RESEARCH_DOSSIER_PROCESS_v1.md for the
full process.

The dossier systematically surveys our 26 clinical sources for
guidance on the specific technique this module teaches: guided
practice sequences, child-specific language, physical cues, common
failure modes, therapeutic mechanisms, pacing recommendations, and
cautions.

**Gate:** Do not proceed to Step 1 until the dossier is compiled,
cross-source synthesis is complete, and Phase A alignment check
shows no unresolved conflicts.

All subsequent steps draw from the dossier. Step 1 (Clinical
Mechanism Extraction) synthesizes the dossier's findings. Steps 3-6
use the dossier's language recommendations, sequence findings, and
cautions. Step 7 (Clinical Cross-Check) verifies the script against
the dossier's source material.

**Why this step exists:** Without the dossier, the script writer
draws from general training knowledge — which may be imprecise,
outdated, or hallucinated. The dossier ensures every script decision
is traceable to a cited clinical source.

## Step 0e — Phase A Fidelity Check on Dossier Synthesis

After the dossier is complete and before proceeding to Step 1, verify
that the dossier's **Recommended Approach** and **Cross-Source
Synthesis** preserve every active element from Phase A — not just
as a mentioned term, but as something the child **does** in the
recommended script structure.

**Procedure:**

Pull the Phase A vocabulary card (or extract it from the Phase A jsx
if no card exists yet). For each key term or action on the card, ask:

> "If I read ONLY the dossier's Recommended Approach and drafted a
> script from it, would this Phase A element survive as an action
> the child performs?"

| Result | Action |
|--------|--------|
| Yes — the element appears as an active verb or child action in the Recommended Approach | Pass. Proceed. |
| Partially — the element is mentioned but absorbed into a broader concept (e.g., "kind words" collapsed into "warmth") | **Flag and revise.** The Recommended Approach must separate the absorbed element back out so the script writer sees it as a distinct action. |
| No — the element doesn't appear in the Recommended Approach at all | **Flag and revise.** Either the clinical sources don't support this element (rare — Phase A was designed from clinical sources) or the synthesis dropped it during distillation. Add it back with source attribution. |

**Why this step exists:** The dossier's cross-source synthesis
distills 5-10 clinical sources into common principles. This
distillation can collapse distinct Phase A elements into a single
clinical concept. In M4 production (April 2026), "kind words/wishes"
(the child's core ACTION in Phase A) was absorbed into "warmth"
(the clinical MECHANISM) during synthesis. The resulting script
guided the child to generate warmth but lost the wish-sending
dimension entirely. This gate catches that collapse before it
reaches the script.

**Gate:** Do not proceed to Step 1 until every Phase A vocabulary
term passes the survival check above. If any term was absorbed or
dropped, revise the dossier's Recommended Approach first.

## Step 1 — Clinical Mechanism Extraction

For each module, write out:

**1a. What is the specific clinical technique?** Name it precisely
and cite the primary source. "Belly breathing" is not enough.
"Diaphragmatic breathing activating parasympathetic response via
vagal tone (Porges, Polyvagal Theory)" is what the script must
guide.

**1b. What does the child's body/mind actually DO?** Describe the
physical or mental action in concrete terms. What would you see if
you watched a child doing this correctly? What would they report
if you asked "what are you doing right now?"

**1c. What is the observable marker that practice is working?** How
does the child (or an observer) know the technique is active? Slower
breathing? Reduced fidgeting? Ability to label a thought? This
marker should appear in the script as a gentle check-in, not a
performance demand.

**1d. What is the common failure mode for this age group?** How do
7-10 year olds typically get this wrong? Breathing from chest instead
of belly. Trying to STOP thoughts instead of watching them. Tensing
harder instead of releasing. The script must preemptively address the
most common failure mode without assuming the child is failing.

**Gate:** If you cannot clearly articulate 1a-1d, the module's
therapeutic mechanism is not well enough understood to write a script.
Return to the clinical sources before proceeding.

## Step 2 — Phase A Language Audit

Pull exact language from the locked Phase A demo for this module:

**2a. Metaphor vocabulary.** What words did Guide Bird use for the
core metaphor? (thought-stream, worry cloud, breathing circle, etc.)
Phase B MUST use these same words. If Phase A said "thought-stream,"
Phase B says "thought-stream" — not "racing thoughts" or "busy mind."

**2b. Action vocabulary.** What verbs did Guide Bird use for the
skill? (watch, breathe, squeeze, name, send, let go, etc.)

**2c. Physical setup.** What body position or physical action was
established? (hands on tummy, sitting still, lying down, etc.)
Phase B's arrival section must match.

**2d. Bridge language.** What did the settled/bridge state say? What
did the transition cue say? Phase B's opening must feel like a
seamless continuation of these.

**2e. Emotional frame.** What emotional vocabulary did Phase A use?
(calm, strong, brave, soft, warm, etc.) Per the Language Consistency
Rule (§3.2), Phase B maintains this frame.

**Output:** A vocabulary card listing the exact words Phase B must use
and must not contradict.

## Step 3 — Draft Script Using Structural Template

Every Phase B script follows a 7-section structure:

### Section 1: WELCOME (3-5 seconds, ~5-15 words)

The meditation voice arrives. Warm greeting that acknowledges the
child's arrival and names the domain magic. This is where the child
meets the voice — it must have character.

- Sets tone immediately: warm, wise, unhurried
- Names the domain magic being practiced ("the magic of Calm")
- Uses gender personalization from child's profile ("young man" /
  "young lady")
- Never rushes — this beat establishes trust

**Pattern:** "Ahh... you've come to learn the magic of [Domain].
Good."

### Section 2: CONNECTION (5-8 seconds, ~10-20 words)

Bridge from what they just saw (Phase A) to what they're about to do
(practice). Uses Phase A vocabulary from the language audit.

- References Phase A's metaphor using exact vocabulary (Step 2a)
- Frames the transition from watching to doing ("Now it's your turn")
- Never re-teaches — assumes the child understood Phase A

**Pattern:** "You saw [Phase A metaphor reference — exact vocabulary].
Now it's your turn."

**Example:** "You saw the breath travel all the way down to the
belly — that's where the magic lives. Now it's your turn."

### Section 3: SETUP (5-10 seconds, ~10-20 words)

Guide the child into physical position. This section exists because
of §3.1a (Described ≠ Executed) — the bridge may have *described*
positioning but Phase B must *instruct* it.

- Explicit physical instructions ("Put your hand right on your belly")
- Confirms what they can already feel ("You can feel yourself
  breathing in and out")
- Transitional framing ("Here's what I want you to do")
- Never assumes physical anchors are already in place unless the
  transition cue explicitly instructed them

**Pattern:** "[Physical instruction]. You can feel [current
sensation]. Here's what I want you to do."

### §3.1a Physical Setup Execution (Described ≠ Executed)

If Phase A's bridge described a physical action in future tense
("you're going to put your hand on your belly") but no explicit
instruction to *perform* it was given before Phase B begins, the
Phase B script must include the instruction in the Setup section.

**The meditation voice must guide any physical anchor into place,
not assume it happened.** A 7-year-old who hears "you're going to
put your hand on your belly" and then "close your eyes" may not
have actually placed their hand. Described ≠ executed.

**Rule:** Phase B scripts must audit every physical anchor assumed
in the Instruction section and verify that either (a) an explicit
instruction to perform it was given in the transition cue, or (b)
the Phase B script itself includes the instruction in its Setup
section.

### Section 4: INSTRUCTION (15-30 seconds, ~30-60 words)

The actual guided practice. This is where the clinical technique
lives. Every sentence must pass the Body Test (Step 4).

Rules:
- Specific, concrete, body-based directions
- One instruction per sentence — never compound
- Repeat key instructions 2-3 times with slight variation
- Verbal guidance at least every 5-8 seconds (no long silences
  for first-time practitioners)
- Paced with the practice: breathing instructions sync with actual
  breath timing; body scan instructions allow time for attention to
  move
- Conditional language for internal experiences: "notice if..."
  / "see what happens..." — never "you will feel..."
- Preemptively address the most common failure mode (Step 1d) without
  assuming the child is failing: "If your tummy isn't moving much,
  put your hand there — it helps"

**Pattern:** "[Instruction]. [Pause for execution]. [Gentle
observation or encouragement]. [Repeat with variation]. [Pause]."

### Section 5: DEEPENING (10-25 seconds, ~20-50 words)

Extend the practice. Options (choose one per module):
- Another cycle at slower pace ("Let's try that one more time, even
  slower")
- A subtle expansion ("Now notice your shoulders too")
- A counting/rhythm anchor ("This time, I'll count with you")
- Increased silence between guidance (for release-based skills)

This section is where the practice becomes slightly more independent.
The narrator guides less, the child does more. Mind-wandering
normalization goes here if anywhere ("If your brain starts thinking
about other things, that's OK. Just feel your belly again.").

### Section 6: LANDING (3-8 seconds, ~5-15 words)

Name what the child just did in Everdale terms. One line. Quiet power.

- Names the domain magic ("That feeling right there... that calm...
  that's your magic")
- Never evaluates performance ("great job" belongs in Rescue/Win,
  not here)
- Never breaks the meditative state with a jarring shift in tone

**Pattern:** "That feeling right there... that [domain quality]...
that's your magic."

### Section 7: EXIT (3-5 seconds, ~5-10 words)

Encourage the child to stay in the state. Does NOT end the practice
— the Rescue sustain does that. The Exit creates a seamless bridge
into the Rescue.

- Encourages continuation, not conclusion
- Trails off gently — the Rescue sustain picks up seamlessly
- Never says "well done" or "you did it" (that's the Win's job)

**Pattern:** "Stay right there. Just keep [core action]."

**Example:** "Stay right there. Just keep breathing."

---

**Total word count target:** 120-200 words (at ~2 words/second +
breathing synchronization pauses = 60-120 seconds)

**Note on timing:** Word count alone underestimates duration for
breathing modules because the narrator synchronizes with real breath
cycles. A 155-word belly breathing script takes ~85-90 seconds
because pauses between instructions are timed to actual inhale/exhale
duration, not reading pace.

## Step 4 — Body Test

For every instruction in Sections 3 (Setup), 4 (Instruction), and 5 (Deepening), answer:

**"If I watched a 7-year-old following this instruction, what would
I see their body doing?"**

| Answer | Action |
|--------|--------|
| Specific physical action (hand rises, shoulders drop, breath slows) | Keep — instruction is concrete enough |
| "Nothing visible, but they'd know what to do" | Acceptable ONLY for mental-skill modules (Thought Clouds, Sleepy Stargazing) — apply the Explain Test below |
| "Nothing — it sounds nice but doesn't direct action" | Cut or rewrite — this is atmosphere, not instruction |

**Explain Test (for mental-skill modules):** Could a 7-year-old
explain to a friend what they're doing? "I'm watching my thoughts
go by" = passable. "I'm cultivating non-judgmental awareness" =
fail. If the child couldn't explain it, the instruction is too
abstract.

---

## Step 5 — Negative Space Check

Verify the script does NOT contain:

| Forbidden Pattern | Why | Fix |
|---|---|---|
| Assumed experience: "Feel the warmth spreading" | Child may not feel warmth; tells them they're doing it wrong if they don't | Conditional: "Notice if there's any warmth" or "See what happens" |
| Assumed pathology: "Your worries are..." | Not every child has worries in this moment | Conditional: "If a worry comes..." |
| Outcome promises: "You'll feel calmer" | Sets up failure if they don't feel calm | Process focus: "Just keep breathing like that" |
| Efforting for release skills: "Try to relax" / "Make your mind quiet" | Paradoxical — trying to relax creates tension | Permission: "You don't have to do anything" |
| Competitive framing: "Try to breathe longer this time" | Turns practice into performance | Remove comparison |
| Countdown pressure: "We have 30 more seconds" | Clock-watching replaces practice | Never reference time remaining |
| Sensory commands: "Feel your feet on the floor" (for non-grounding modules) | Not all modules involve body awareness; this is grounding-specific instruction | Use only for grounding modules (9, 10) |
| Abstract instruction: "Connect with your inner calm" | Meaningless to a 7-year-old | Concrete: "Let your shoulders drop" |
| New vocabulary not established in Phase A | Breaks language consistency; child loses the thread | Use only words from Step 2 vocabulary card |
| Evaluative language: "Good job" / "You're doing great" | Breaks meditative state; creates performance pressure | Save for Rescue/Win |

## Step 6 — Age-Down Pass

Read the script as a fidgety, concrete-thinking 7-year-old who has
never meditated and doesn't want to sit still.

For each line:
- [ ] Would this child understand every word? (no word over ~3
  syllables unless already taught in Phase A)
- [ ] Would this child know what to do with their body RIGHT NOW?
  (not "eventually" or "in general")
- [ ] Is there a gap longer than 8 seconds where nothing is said?
  (kids lose focus in silence — guide verbally at least every
  5-8 seconds for beginners)
- [ ] Does the script keep them engaged without being stimulating?
  (engagement through curiosity and body awareness, not excitement)
- [ ] Does the script use "you" consistently? (never "we" — the
  narrator is guiding, not practicing alongside)
- [ ] Is the energy arc correct? (starts gentle, deepens into
  practice, lands softly — never peaks in the middle)

**Pacing test:** Read aloud at meditation pace (~2 words per second).
Time it. If over 90 seconds, cut from Deepening first. If under 45
seconds, Instruction needs more repetition/guidance.

---

## Step 7 — Clinical Cross-Check

Compare the finished script against the primary clinical source
cited in Step 1a:

- [ ] Does the script deliver the technique the source describes?
  (not a loosely inspired version — the actual technique)
- [ ] Are there any instructions I added that aren't supported by
  the clinical literature? (additions are the hallucination risk)
- [ ] Are there any simplifications that accidentally removed the
  therapeutic mechanism? (e.g., simplifying PMR so much that
  the tension-release contrast is lost)
- [ ] If a child therapist read this script, would they recognize
  the technique and consider it correctly guided?

**MISMATCH FLAG format:** If the clinical technique requires
something Phase A didn't set up, or Phase A's metaphor contradicts
what the technique needs:

> MISMATCH FLAG: Phase A uses [X metaphor/vocabulary] but Phase B
> practice requires [Y action/framing]. Specifically: [describe the
> gap]. Resolution options: [suggest Phase A correction OR script
> adaptation]. Recommend: [which option preserves therapeutic
> integrity].

Mismatch flags halt production on that module until resolved.

---

## Step 8 — Phase A Alignment Verification

Read these four elements IN SEQUENCE as one continuous experience:

1. Phase A settled/bridge text
2. Phase B transition cue
3. Phase B script (full)
4. Rescue sustain ("That's great... stay right there...")

Check:
- [ ] Does the vocabulary stay consistent across all four? (no
  sudden word changes)
- [ ] Does the energy arc make sense? (instruction → bridge →
  calm arrival → guided practice → gentle sustain)
- [ ] Does the script deliver what Phase A's bridge promised?
- [ ] Does the Rescue "stay right there" make sense after
  what the script just guided? (the child should know what
  state to sustain)
- [ ] Is there any content that contradicts Phase A's teaching?
- [ ] Is there any content that REPEATS Phase A's teaching?
  (Phase B practices, it doesn't re-teach)

---

## Step 9 — Kim Review

Present each script with:
1. Clinical mechanism extraction (Step 1, all four parts)
2. Phase A vocabulary card (Step 2)
3. The script itself
4. Body Test results for each instruction line (Step 4)
5. Any Mismatch Flags (Step 7)
6. Timing (read-aloud duration in seconds)

Kim validates:
- Therapeutic accuracy
- Child-appropriateness
- Language feels natural, not clinical
- The script is something she would use with a real child client

## Step 9b — Embed Audio Cue Markers

**Added v1.2 (February 24, 2026).** After Kim approves the script and before handing off to the Audio Assembly pipeline, embed audio cue markers into the script. These markers tell the automated mixing pipeline exactly where to place sound effects (breath tones, bells, noticing tones, etc.).

**Marker syntax:**
- `{{INHALE_CUE}}` — place inhale wind sound on the NEXT line
- `{{EXHALE_CUE}}` — place exhale wind sound on the NEXT line
- `{{BELL_CUE}}` — place transition bell on the NEXT line
- `{{NOTICING_CUE}}` — place noticing tone on the NEXT line
- `{{PAUSE:Xs}}` — silent pause of X seconds

**Placement rule:** The marker goes on the line BEFORE the narration it accompanies. The sound starts at the same moment the narrator begins speaking that line.

**Why this step exists:** The word "breathe" (and similar cue words) often appears multiple times in a script — sometimes as description ("the long breath out is where the magic is"), sometimes as actual instruction ("Breathe in... 2, 3, 4"). Without markers, the automated pipeline cannot tell which occurrence is the real cue and may place tones on the wrong words. This caused an 8-second timing error during M2 production.

**Example (M2, breathing module):**
```
Here we go.

{{INHALE_CUE}}
Breathe in... one... two... three... four...

Now keep the air inside... one... two... three... four... five... six... seven...

{{EXHALE_CUE}}
And let it out, nice and slow... one... two... three... four... five... six... seven... eight.
```

**Example (M3, observation module):**
```
Now ask yourself — I wonder what my next thought will be?

{{PAUSE:8s}}
{{NOTICING_CUE}}
Have you noticed one?
```

**Checklist:**
- [ ] Every breathing cycle has `{{INHALE_CUE}}` and `{{EXHALE_CUE}}`
- [ ] Bell placement marked with `{{BELL_CUE}}` if applicable
- [ ] Observation modules have `{{NOTICING_CUE}}` at check-in points
- [ ] No orphaned markers (every cue has a corresponding sound in the design)
- [ ] Markers are placed BEFORE (not after) their target narration line

**Note:** These markers are stripped before sending the script to ElevenLabs TTS. They exist only for the mixing pipeline.
